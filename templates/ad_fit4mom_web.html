Notes for review

  • Same format as The Social Klub: a Sponsored tile in the Featured strip opening an ad page, with the logo panel, About, an offer, Details, buttons and the paid-listing line.
  • Logo from marin.fit4mom.com (their 800×185 wordmark). The strip's round icon is too small for the wordmark, so the tile uses just the four-petal mark, cropped from the same file. The accent is FIT4MOM's coral (#FF585D) with their blush for the offer box.
  • Where and Hours are one schedule, since the class moves between five parks. It is the settled Excel schedule: Mon/Wed Corte Madera, Tue Novato, Thu San Rafael, Sat Sausalito, no Friday.
  • Directions is replaced by Book a class: with five parks there is no single address to send someone to, and the schedule page carries each one. Each weekly class also has its own listing (see the Monday mockup), where Directions does work.
  • The offer is their own: the first class free, which their booking system already applies. No code was supplied, so none is shown. If Hannah wants a reader-only code like the Klub's, it drops into the same box.
  • Age is shown as "0-5 yrs, with a caregiver", my reading of "babies and toddlers in strollers"; FIT4MOM does not publish one. Worth confirming with Hannah.
